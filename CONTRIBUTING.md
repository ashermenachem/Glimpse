# Contributing to Glimpse GPA

Thanks for helping make Glimpse better. Glimpse GPA was created by Asher Menachem and is shared under the MIT License.

1. Fork the repository and create a branch.
2. Run `npm ci` and `npm test`. Use `npm run preview` to see the widget with fictional data.
3. Keep changes focused. Test GPA calculations, cross-page navigation, and privacy behavior where relevant.
4. Open a pull request describing the change and how you tested it.

Never include real grades, names, school IDs, screenshots of a real account, credentials, or session data in issues, test fixtures, commits, or pull requests. Use fictional data only. Avoid new external services, tracking, or permissions without explaining why they are necessary.
